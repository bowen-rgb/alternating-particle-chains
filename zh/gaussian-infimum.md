# 交替高斯粒子链的能量下确界与最小间距的精确代价

**GPT-6.2 Astra**

[中文 PDF](gaussian-infimum.pdf) · [English PDF](../en/gaussian-infimum.pdf) · [English text](../en/gaussian-infimum.md)

**摘要**　考察由偶数个粒子组成的一维周期链，粒子沿链交替取正、负两种符号。对固定周期和粒子数，在一个显式的高斯宽度范围内，证明能量在允许碰撞的构型闭包上取到最小值，并刻画所有取等构型。若相邻粒子之间至少相距 $`h`$，则当 $`h`$ 趋于零时，最小能量比无间距约束时的下确界高出一个二阶量。本文求得其精确系数，并证明最优构型聚集于相隔半周期的两点附近，两簇所含粒子数均为奇数且尽量接近。

**关键词**　交替粒子链；周期高斯势；圆周重排不等式；能量极小化

## 1　周期模型与能量下确界

Bétermin、Knüpfer 与 Nolte [1，猜想 2.7] 提出：若 $`f(r)=F(r^2)`$ 且 $`F`$ 完全单调，则对势组 $`\mathcal F=(-f,-f,f)`$，在任意密度 $`\rho`$ 下，等距链 $`e^\rho`$ 应在周期交替构型类 $`\mathcal A_N^\rho`$ 中唯一极小（相差整体平移视为相同）。高斯势对应 $`F(t)=e^{-\alpha t}`$，满足该假设；文献 [5] 的四粒子反例却给出了能量更低的排列。本文固定 $`N`$ 与 $`L=N/\rho`$，进一步求所有构型的能量下确界，以及禁止粒子碰撞的二阶能量代价。

一维等距基态、高密度极限及等距与双子格构型的竞争分别见文献 [6–8]。本文的二阶系数取决于交替符号簇的内部间距；只比较等距结构或双子格结构，无法确定所有允许构型的这一系数。

固定周期 $`L>0`$、参数 $`\alpha>0`$ 与偶数 $`N=2m`$。一个周期胞内的位置为 $`0\le x_0<\cdots<x_{N-1}<L`$，按 $`x_{j+N}=x_j+L`$ 延拓。粒子符号为 $`\sigma_j=(-1)^j`$。同类粒子的相互作用势为负高斯，异类为正高斯。依文献 [1，定义 2.1] 的双向计数约定，记

```math
G(x)=\sum_{k\in\mathbb Z}e^{-\alpha(x+kL)^2},\qquad Q=\sum_{i,j=0}^{N-1}\sigma_i\sigma_jG(x_i-x_j),\qquad E=1-\frac{Q}{N}.\qquad\text{(1)}
```

常数 $`1`$ 扣除本胞中每个粒子的零距离自作用，其他周期的镜像仍计入。允许相邻粒子重合时，$`E`$ 按式（1）连续延拓。在下文中使用无量纲参数

```math
s=\alpha L^2,\qquad q=e^{-\pi^2/s},\qquad c=\frac{\sqrt{\pi/\alpha}}{L},\qquad g(\theta)=G\!\left(\frac{L\theta}{2\pi}\right).\qquad\text{(2)}
```

**定理 1（下确界与取等构型）** 设 $`q\le 1/3`$。严格有序构型的每粒子能量下确界为

```math
I_N=1-\frac{2}{N}\,[G(0)-G(L/2)]=1-\frac{8c}{N}\sum_{j=0}^{\infty}q^{(2j+1)^2}.\qquad\text{(3)}
```

在碰撞闭包中，取等当且仅当抵消所有同点的正负粒子后，剩下一正一负两个粒子且相距半个周期。中性重合对可以位于胞内其他位置。对于严格有序的构型，$`N=2`$ 时对径排列取等；$`N\ge4`$ 时下确界不能取到。

## 2　圆周重排与定量稳定性

以 $`\theta=2\pi x/L`$ 为角坐标。设 $`A`$ 为从每个正粒子沿正向到下一个负粒子的弧段之并，$`|A|`$ 表示角长度。圆周上指示函数 $`\mathbf1_A`$ 的分布导数是带符号的粒子测度 $`\mu`$。对光滑偶周期函数 $`v`$，在两变量上各分部积分一次，得

```math
Q_v(A):=\iint v(u-w)\,d\mu(u)\,d\mu(w)=\int_A\!\int_A[-v''(u-w)]\,du\,dw.\qquad\text{(4)}
```

若 $`A`$ 是长度为 $`a`$ 的单弧，端点处为相反的两个单位质量，故 $`Q_v(A)=2[v(0)-v(a)]`$。碰撞使零长度弧消失或使相邻弧合并，上式仍然成立。

**引理 1（由带符号相互作用到圆周重排）** 设 $`v`$ 为光滑偶函数，周期为 $`2\pi`$，且 $`v`$ 与 $`-v''`$ 在 $`[0,\pi]`$ 上均单调不增。对任意有限弧并 $`A`$ 和任意半圆 $`H`$，均有 $`Q_v(A)\le Q_v(H)`$。

**证明** 取 $`C=\max\{0,\max v''\}`$，使 $`K=C-v''`$ 非负、偶对称并在半周期上单调不增。文献 [2，定理 4.1] 对两个非负函数及这样的周期核成立。令两个函数均为 $`\mathbf1_A`$，其对称递减重排即等长单弧 $`J`$ 的指示函数。于是

```math
\int_A\!\int_A K(u-w)\,du\,dw\ \le\ \int_J\!\int_J K(u-w)\,du\,dw.
```

两边减去相同的 $`C|A|^2`$，即得 $`Q_v(A)\le Q_v(J)`$。又 $`Q_v(J)=2[v(0)-v(|A|)]\le 2[v(0)-v(\pi)]`$，最后一步用到了周期对称性及 $`v`$ 在半周期上的单调性。$`\square`$

### 第一傅里叶模与余核的单调性

由泊松求和公式，$`g(\theta)=c[1+2\sum_{n\ge1}q^{n^2}\cos(n\theta)]`$，各阶导数级数均绝对收敛。取 $`\beta=q/3`$ 以保留显式正裕量（此选择未经优化），置 $`v(\theta)=g(\theta)-2c\beta\cos\theta`$。对 $`0<\theta<\pi`$，由 $`|\sin(n\theta)|\le n\sin\theta`$，可将 $`v'`$ 及 $`(-v'')'`$ 的高阶模统一控制在 $`2cqR(q)\sin\theta`$ 以内，其中

```math
R(q)=\sum_{n=2}^{\infty}n^4q^{n^2-1}\le\frac{16}{27}\cdot\frac{48}{47}<\frac23.\qquad\text{(5)}
```

确实，$`q\le1/3`$ 时首项不超过 $`16/27`$，相邻两项之比不超过 $`(3/2)^4(1/3)^5=1/48`$。两导数的首模均为 $`-2c(q-\beta)\sin\theta`$，故引理 1 可用于 $`v`$。令 $`z=\int_Ae^{i\theta}\,d\theta`$。被分出的首模对 $`Q_g(A)`$ 的贡献为 $`2c\beta|z|^2`$，半圆对应的 $`|z|`$ 为 $`2`$，从而

```math
Q_g(H)-Q_g(A)\ge 2c\beta(4-|z|^2).\qquad\text{(6)}
```

**定理 2（半圆稳定性）** 设 $`d(A)=\min_H|A\triangle H|`$，其中 $`H`$ 遍历所有半圆，$`\triangle`$ 表示对称差。在定理 1 的假设下，

```math
E-I_N\ge\frac{16c\beta}{N}\left[1-\cos\!\left(\frac{d(A)}4\right)\right].\qquad\text{(7)}
```

**定理 1、2 的证明** 取 $`\phi=\arg z`$（$`z=0`$ 时任取），并令 $`H_\phi=\{\cos(\theta-\phi)>0\}`$。把 $`e^{-i\phi}z`$ 的实部写成积分，得到

```math
2-|z|=\int_{A\triangle H_\phi}|\cos(\theta-\phi)|\,d\theta.\qquad\text{(8)}
```

对给定长度 $`a`$，右侧被积函数在两个零点两侧的四段区间上取值最小。每段取宽 $`a/4`$，可得积分下界 $`4[1-\cos(a/4)]`$。令 $`a=|A\triangle H_\phi|\ge d(A)`$，由 $`4-|z|^2\ge2(2-|z|)`$ 和式（6）得到式（7），此处半圆的能量为 $`1-2[g(0)-g(\pi)]/N`$。

半圆的傅里叶能量正是式（3）。若能量达到半圆值，则 $`Q_g(H)-Q_g(A)=0`$。在式（6）中，余核的亏损非负，首模的亏损 $`2c\beta(4-|z|^2)`$ 也非负，故两者均为零。由于 $`\beta>0`$，必有 $`|z|=2`$。式（8）的积分随之为零，而 $`|\cos(\theta-\phi)|`$ 仅在两个端点为零，因此 $`|A\triangle H_\phi|=0`$。此时余核也取半圆值，两个指示函数的分布导数相同，恰为一对对径的异号单位质量。反之，导数相同的两个指示函数之差为常数，而半圆内外均有正测度，故该常数为零。严格有序的 $`N`$ 个粒子产生 $`N`$ 个跳跃。对任意偶数 $`N`$，在 $`0`$ 固定一个正粒子，把其余 $`N-1`$ 个交替粒子收缩至 $`\pi`$，即可用严格有序构型逼近式（3）。两定理得证。$`\square`$

## 3　加入最小间距后的最优能量

以下固定 $`N=2m\ge4`$、$`L`$ 和 $`\alpha`$，并保持 $`q\le1/3`$。要求所有相邻间距（含跨周期的间距）至少为 $`h`$，其中 $`0<h\le L/N`$。记最低能量为 $`M_N(h)`$，并置

```math
\eta=\frac{2\pi h}{L},\qquad D=g''(\pi)-g''(0)=4c\sum_{\substack{n\ge1\\n\ \mathrm{odd}}}n^2q^{n^2}>0.\qquad\text{(9)}
```

**定理 3（小间距渐近式与粒子分簇）** 当 $`h\downarrow0`$ 时，

```math
M_N(h)=I_N+\frac{\lfloor m^2/2\rfloor}{N}D\,\eta^2+O_{N,L,\alpha}(\eta^4).\qquad\text{(10)}
```

对充分小的 $`h`$，每个极小构型经旋转后分为两簇，各位于一对对径点的 $`O(\eta)`$ 邻域内。两簇分别含 $`2k+1`$ 和 $`2l+1`$ 个粒子，其中 $`k+l=m-1`$ 且 $`|k-l|\le1`$。

### 极小值存在与试探上界

固定一个粒子后，允许的循环间距构成非空紧单纯形；能量连续，故极小值存在。在 $`0`$ 留一个正粒子，另将 $`N-1`$ 个粒子以角间距 $`\eta`$ 对称置于 $`\pi`$ 附近。两簇间的间距为 $`\pi-(m-1)\eta\ge\eta`$。这族构型写为 $`\theta_i=b_i+t_i\eta`$，其中 $`b_i\in\{0,\pi\}`$、$`|t_i|\le m-1`$。因 $`g'(0)=g'(\pi)=0`$，每一有序对的二阶泰勒估计给出

```math
0\le M_N(h)-I_N\le C_{\mathrm{tr}}\eta^2,\qquad C_{\mathrm{tr}}=2N(m-1)^2\|g''\|_\infty .\qquad\text{(11)}
```

### 3.1　全部粒子的统一定位

**引理 2（定位常数）** 置 $`B=NC_{\mathrm{tr}}/(4c\beta)`$，$`C_0=\max\{1,\tfrac12+\pi B\}`$。每个极小构型均可旋转，使其所有粒子到 $`\{0,\pi\}`$ 的角距离至多为 $`C_0\eta`$。

**证明** 将式（8）选定的半圆旋转为 $`H=(0,\pi)`$。由式（6）、（8）、（11）及 $`4-|z|^2\ge2(2-|z|)`$，

```math
\int_{A\triangle H}|\sin\theta|\,d\theta\ \le\ B\eta^2.\qquad\text{(12)}
```

任取一个粒子，设其到最近端点的角距离为 $`r`$。若 $`r<\eta`$ 则已满足结论。若 $`\eta\le r\le\pi/2`$，在该粒子两侧各取长度为 $`\eta/2`$ 的区间。区间内部不含其他粒子，也不越过半圆端点。$`\mathbf1_A`$ 在该粒子处跳变而 $`\mathbf1_H`$ 保持常值，因此至少有一侧全部属于对称差（端点除外）。

在这一侧，任一点到最近端点的距离至少为 $`r-\eta/2`$。由 $`\sin u\ge 2u/\pi`$（$`0\le u\le\pi/2`$），这个区间对式（12）左端的贡献至少为 $`(\eta/\pi)(r-\eta/2)`$。与上界比较即得 $`r\le(\tfrac12+\pi B)\eta`$。同一常数适用于每个粒子和每个极小构型。$`\square`$

取 $`\eta`$ 足够小，使 $`C_0\eta<\pi/4`$ 且 $`B\eta^2<\sqrt2`$。两簇以外的两段大弧上，$`\mathbf1_A`$ 分别为常值。若与 $`\mathbf1_H`$ 不一致，$`[\pi/4,3\pi/4]`$ 或其对径弧将全部落在对称差内；其权积分等于 $`\sqrt2`$，与式（12）矛盾。故靠近 $`0`$ 的簇净符号为 $`+1`$，靠近 $`\pi`$ 的簇净符号为 $`-1`$。因符号交替，两簇粒子数均为奇数。

### 3.2　交替簇的有符号二阶矩

将一个奇数簇内的符号归一化为 $`\epsilon_i=(-1)^i`$，记从相应端点量起的有序偏移为 $`u_0,\ldots,u_{2k}`$，并令

```math
P=\sum_{i=0}^{2k}\epsilon_i u_i,\qquad V=\sum_{i=0}^{2k}\epsilon_i u_i^2-P^2.\qquad\text{(13)}
```

因 $`\sum_i\epsilon_i=1`$，$`V`$ 在整个簇共同平移下不变。可设 $`u_0=0`$，依次记内部间距为 $`a_1,b_1,\ldots,a_k,b_k`$。此时 $`P=\sum_j b_j`$。把相邻平方项相减，得 $`\sum_i\epsilon_i u_i^2=\sum_j(2u_{2j-1}b_j+b_j^2)`$。代入式（13）并消去 $`P^2`$，有

```math
V=2\sum_{j=1}^k b_j\sum_{i=1}^j a_i\ \ge\ k(k+1)\eta^2.\qquad\text{(14)}
```

各间距均等于 $`\eta`$ 时取等。对单粒子簇，两边均为零。

### 3.3　一致的四阶余项与簇大小的选择

**定理 3 的证明（续）** 用下标 $`0,\pi`$ 区分两簇的 $`P,V`$。两簇内均按式（13）归一化符号；计算簇间相互作用时须恢复相反的净符号。令 $`C_*=\max\{C_0,m-1\}`$。对极小构型，引理 2 给出 $`|u_i|\le C_*\eta`$；下文构造的对称试探构型也满足这个界。

每个有序粒子对对应 $`g(b+t)`$，其中 $`b=0`$ 或 $`\pi`$（按周期取值），$`|t|\le2C_*\eta`$。两个中心处的一阶、三阶导数均为零。令 $`K_4=\|g^{(4)}\|_\infty`$，泰勒定理给出逐对估计

```math
\left|g(b+t)-g(b)-\tfrac12 g''(b)t^2\right|\le \frac{K_4}{24}(2C_*\eta)^4.\qquad\text{(15)}
```

簇内用恒等式 $`\sum_{i,j}\epsilon_i\epsilon_j(u_i-u_j)^2=2V`$。两簇间的对应和为 $`V_0+V_\pi+(P_0-P_\pi)^2`$。计入两个方向并用 $`NE=N-Q`$，得到

```math
\begin{aligned}N(E-I_N)&=D(V_0+V_\pi)+g''(\pi)(P_0-P_\pi)^2+\mathcal R,\\ |\mathcal R|&\le C_R\eta^4,\qquad C_R=\frac{N^2K_4}{24}(2C_*)^4.\end{aligned}\qquad\text{(16)}
```

余项界来自至多 $`N^2`$ 个有序对，故与所选极小构型及簇的分组无关。由傅里叶级数和式（5），$`g''(\pi)\ge2cq[1-R(q)]>0`$。式（14）与式（16）因此给出

```math
N(E-I_N)\ge D[k(k+1)+l(l+1)]\eta^2-C_R\eta^4 .
```

在非负整数 $`k+l=m-1`$ 中，若 $`k\ge l+2`$，把 $`(k,l)`$ 换为 $`(k-1,l+1)`$ 可使括号内的整数减少 $`2(k-l-1)`$。故最小值仅在 $`|k-l|\le1`$ 时达到，代入得 $`\lfloor m^2/2\rfloor`$。

取这样的 $`k,l`$，使两个奇数簇分别关于 $`0,\pi`$ 对称，簇内间距均为 $`\eta`$。此时 $`P_0=P_\pi=0`$，式（14）两次取等，簇间间距 $`\pi-(m-1)\eta`$ 合法。对该构型应用式（16）即得匹配的上界，遂证式（10）。任一非均衡分组的二阶系数在 $`N(E-I_N)`$ 中至少增加 $`2D`$；当 $`2D\eta^2>2C_R\eta^4`$ 时，它无法达到极小值。综合可行性、引理 2 后的两项定位条件及上述分组比较，一个充分阈值为

```math
h_0=\frac{L}{2\pi}\min\!\left\{\frac{2\pi}{N},\,\frac{\pi}{4C_0},\,\sqrt{\frac{\sqrt 2}{B}},\,\sqrt{\frac{D}{C_R}}\right\}.
```

对 $`0<h<h_0`$，上述分簇结论成立。$`\square`$

以 $`N=L=4,\ \alpha=1/4`$ 为例，上式给出 $`h_0\approx1.19263\times10^{-5}`$。这是统一误差界导出的充分值，不能据此确定分簇失效的实际间距。

### 四粒子与六粒子的区别

对于四粒子，最优分组只有 $`1+3`$。对于六粒子，$`1+5`$ 与 $`3+3`$ 在无间距约束时都可收缩为同一个对径偶极子，但两种紧密对称构型的二阶系数之比为 $`6:4`$。因而无约束问题的取等分类本身并不能预测施加小间距后会选择哪一种排列。

### 宽度范围以外的竞争构型

条件 $`q\le1/3`$ 等价于 $`s=\alpha L^2\le\pi^2/\log3\approx8.984`$。记 $`E_{\rm dip}^{(N)}=1-2[G(0)-G(L/2)]/N`$ 为对径偶极子的能量，此记号在定理覆盖范围以外亦有意义。取 $`L=1,\ s=22`$，考虑闭包内的交替六粒子构型

X=(0,\tfrac18,\tfrac18,\tfrac14,\tfrac12,\tfrac34).\qquad\text{(17)}

位于 $`1/8`$ 的两个异号粒子抵消，余下四个等距粒子的带符号测度与原六粒子构型相同。若 $`E_{\rm eq}^{(4)}`$ 为该四粒子链的能量，由式（1）的归一化，

```math
E(X)=1-\tfrac46(1-E_{\rm eq}^{(4)})\approx0.665009396 < 0.669391181\approx E_{\rm dip}^{(6)}.\qquad\text{(18)}
```

两侧可由式（1）直接计算：截取 $`|k|\le3`$，因 $`|x_i-x_j|\le1`$，每粒子能量误差至多为 $`12e^{-198}/(1-e^{-154})`$。由连续性，把重合对稍微分开仍保持严格不等式。因此在 $`s=22`$ 时，对径偶极子已失去全局最优性。该比较给出一个更低的竞争构型，六粒子全局极小构型的分类仍然开放。

对 $`N=4`$，在单位周期的 $`120`$ 等分网格上固定一个正粒子，枚举另外三个非降序位置（允许重合）。在 $`s=18`$ 时网格最低能量与偶极子能量同为 $`0.5111089813`$；在 $`s=22`$ 时等距四粒子的能量 $`0.4975140939`$ 已低于偶极子能量 $`0.5040867712`$。直接比较这两个四粒子候选的能量，差值在 $`s=21.7707`$ 与 $`21.7709`$ 处异号，二分得到交点 $`s\approx21.77085`$。这是两条候选能量曲线的交点；其他构型可能更早胜出。另在固定 $`N\ge4,L`$ 且 $`\alpha\to\infty`$ 时，等距能量趋于零，而偶极子能量趋于 $`1-2/N>0`$。

更一般地，在任意偶数胞中插入一个同点的异号粒子对，原有带符号测度与 $`Q`$ 均保持不变。记插入后的能量为 $`\widetilde E`$，则

```math
\widetilde E-E_{\rm dip}^{(N+2)}=\frac{N}{N+2}\big(E-E_{\rm dip}^{(N)}\big).\qquad\text{(19)}
```

令 $`S_N`$ 为存在构型严格低于偶极子能量的参数 $`s`$ 的集合，以 $`s_*(N)=\inf S_N`$ 表示首次失优的边界。式（19）给出 $`S_N\subseteq S_{N+2}`$，故 $`s_*(N+2)\le s_*(N)`$。此推论无需假定失优集是区间，也不蕴含严格单调性。

## 5　结语

在 $`q\le1/3`$ 的范围内，无间距约束时允许中性重合对出现在周期胞的不同位置；施加正的最小间距后，定理 3 将所有粒子定位在两个对径点附近，并确定两簇的粒子数。其原因可以从式（16）直接读出：每一簇的交替有符号二阶矩都有一个由簇大小决定的下界，而两簇相对位移的贡献非负。两个下界能够在同一族试探构型上同时取到。

本文固定周期、粒子数及高斯参数，并假设两种符号严格交替。式（15）和式（16）中的常数依赖于这些参数，不能据此取固定密度下的热力学极限。有限正间距时粒子位置的高阶修正、不同粒子数对应的临界宽度，以及宽度范围以外是否存在其他最优簇型，均有待研究。

圆周重排的定量稳定性已有更一般的理论，参见文献 [3]；这里单独保留高斯核的第一模，得到允许 $`|A|`$ 自由变化时的显式常数。竞争相互作用的一维分块极小化可参见文献 [4]，本文的小间距系数则来自式（14）中的交替有符号二阶矩。

### 数值复现

文献 [5] 所列 PR 附有标准库脚本 verify_gaussian_infimum.py。表 1 和三个六粒子网格值可由该脚本复核。式（18）及四粒子网格计算的独立复核步骤如下：按式（1）预先计算网格差值处的周期核；四粒子情形固定 $`x_0=0`$ 后，枚举 $`x_j=i_j/120`$，其中 $`0\le i_1\le i_2\le i_3<120`$。式（18）则将式（17）的六个位置直接代入双和。计算用于复核，定理 1—3 的结论由解析证明给出。
